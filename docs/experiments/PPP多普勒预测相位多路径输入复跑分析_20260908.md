# 多普勒预测相位多路径输入复跑分析

## 1. 执行范围

使用此前设备专属最优 PPP 设置，对 K80/H111、Find X6/X111、ACE5/A111 的四类新增输入分别进行全历元复跑：

1. `doppler_mp`：多普勒预测相位后的外部伪距多路径改正 RINEX。
2. `doppler_smoothed`：上述数据再进行多普勒平滑伪距。
3. `coarse_cleaned1`：`Coarse error/cleaned1` 数据。
4. `coarse_cleaned2`：`Coarse error/cleaned2-cleaned1` 数据。

处理函数：`CODE/OTHERS/runDopplerPredictedMultipathCompare20260907.m`。
结果根目录：`RESULTS/PPP_DOPPLER_MP_COMPARE_20260907/`。
本轮 manifest：`RESULTS/PPP_DOPPLER_MP_COMPARE_20260907/manifest_20260908_001414.csv`。

所有 N、E、H 指标由浮点解 ECEF 坐标相对于 H111、X111、A111 真值转换得到；RMS 与 P95 单位均为 m。每组均处理完整数据范围：K80、Find X6 为 3600 历元，ACE5 为 2272 历元。

## 5. 最终结论

本轮 12 组完整历元复跑未产生可以直接替代三台手机既有最优方案的新输入。最终保留：

| 设备 | 保留输入与参数 | 原因 |
|---|---|---|
| K80/H111 | 外部伪距多路径改正 RINEX + A9 | 四类新输入的可用性、N/E/H 或 3D 长尾均更差。 |
| Find X6/X111 | 外部伪距多路径改正 RINEX + 原高度角方案 | 两个 Coarse error 版本有精度潜力，但尚损失约 0.95% 可用性且 N P95 变差。 |
| ACE5/A111 | 外部伪距多路径改正 RINEX + A10 | `doppler_mp` 近似持平但可用性下降；其余版本退化。 |

不建议直接把“多普勒平滑伪距”或 Coarse error 清洗作为三台手机的统一默认输入。下一步应针对 Find X6 `coarse_cleaned1` 分析失效历元和北向 P95 升高的来源，在不降低有效率的条件下复验。
