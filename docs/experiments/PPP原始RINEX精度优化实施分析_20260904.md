# 三手机原始 RINEX PPP 精度优化实施分析

日期：2026-09-04
范围：K80/H111、Find X6/X111、ACE5/A111 未进行 Doppler 相位预测的原始 RINEX。

## 1. 最终结论

- K80：采用 A9，3600 历元有效率 99.86%，3D P50/P95 为 3.92/10.46 m。
- Find X6：所有新增候选均产生明显长尾，保留原始“仅高度角”结果，3600 历元有效率 100%，3D P50/P95 为 13.24/16.61 m。
- ACE5：采用 A10，2272 历元有效率 99.87%，3D P50/P95 为 5.68/11.67 m。
- 逐星座逐频标准差和相对 C/N0 倍率基础设施已实现，但本数据中 A4--A8 出现长尾，未进入最终模板。
- 软多路径已经实现；A8 未超过不启用软多路径的候选，因此最终关闭。

参考坐标来自当前 `DATA/COORDS/Coords.txt`。如果它们不是测量级真值，本文精度应解释为相对参考坐标误差。

## 3. 核心实现

### 3.1 Doppler 周跳

- 梯形积分替代逐卫星几何均值和正负号取最小值。
- 按星座选择统一 Doppler 符号。
- 去除星座公共中位数。
- 使用 `max(固定下限, MAD 系数)` 门限。
- 新增 `D_system_freq_enable(星座,频率)`。
- Find X6 仅关闭 Galileo 第三频 Doppler 判决，其第三频码相位仍保留。

最终门限：K80 2 cycle，Find X6/ACE5 3 cycle，MAD 系数 6。

### 3.2 TDCP

- `cs_found_TDCP` 改为卫星×频率矩阵。
- 新增 `TDCP_log_only`，记录模式不修改解算。
- 新增 MAD 标准化门限、最少卫星数和最大剔除数。
- 每频最多剔除 2 条，至少保留 6 星。
- 删除 `sigma0` 强制截断到 1 的行为。
- 确认模式只重置发生异常的频率，不扩散到整颗卫星全部频率。
- 每历元进入函数时重建缓存，修复分段重置后卫星数改变导致的维度错误。

最终：K80绝对下限0.08 m，ACE5 0.15 m，标准化系数5。

### 3.3 随机模型

- 支持各星座各频率独立码/相位标准差。
- 支持相对于频点基础标准差的 C/N0 倍率。
- 码和相位倍率独立。
- 实验显示一次性使用较保守逐频表会降低滤波增益并产生长尾，因此最优 A9/A10 恢复原始随机模型。

这说明功能实现有效，但当前推荐表仍需更多天、多环境数据标定，不能仅凭一组树荫数据发布。

### 3.4 多路径

- 新增一阶码差分、星座 MAD 门限和 Huber 式软权重。
- 软模式只膨胀码方差，不删除健康相位，也不执行 600 秒冷却。
- K80 A7/A8 短筛 P95 为 8.83/8.85 m，ACE5 A7/A8 均存在长尾；未证明额外收益，最终关闭。

### 3.5 分段与冷启动

- K80 A9：60 秒分段，10 历元多历元冷启动。
- ACE5 A10：30 秒分段，10 历元多历元冷启动。
- Find X6：不分段，保留原结果。

`cs_obs_pct` 包含冷启动阶段主动保持相位的标记，因此 A9/A10 的16.4%/43.4%不能全部解释为真实周跳误报。

## 4. 筛选结果摘要

- A2：稳健 Doppler + TDCP 记录；K80较稳定，X6/ACE5存在漂移。
- A3：TDCP进入确认；K80与A2接近，X6仍有长尾。
- A4：逐星座逐频标准差；三台均出现不同程度退化。
- A5：A4 + C/N0相对倍率 + BDS GEO降权；未解决长尾。
- A7：A5 + 60秒分段；K80短筛很好，但全时段P95 357.31 m，淘汰。
- A8：A7 + 软多路径；没有稳定额外收益。
- A9：原随机模型 + TDCP确认 + 60秒分段；K80全时段最优。
- A10：原随机模型 + TDCP确认 + 30秒分段；ACE5全时段最优。

## 6. 已知限制

- ACE5 A10 的 >100 m 比例为0.617%，略高于原计划0.5%硬目标；虽然P95和有效率大幅改善，仍需继续定位少量异常分段。
- 固定30/60秒重置属于稳定化措施，不是周跳识别的最终理论解。
- Find X6对稳健公共项处理敏感，新增候选全部存在长尾，需单独研究Galileo E5b Doppler及钟差模型。
- 逐频标准差表不能只依据验后残差一次拟合，应使用多天、多环境训练/验证集。
- ACE5只包含2272处理历元，与目录标称59分钟不一致，需要回查原RINEX缺测或处理时间窗。
