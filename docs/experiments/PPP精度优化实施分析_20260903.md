## 4. 根因与实现

### 4.1 周跳

原 Doppler 0.5 cycle 门限使三台几乎每个历元都产生周跳标记，模糊度连续性被破坏。新实现改为：

1. 梯形 Doppler 积分；
2. 每个星座统一选择 Doppler 符号；
3. 去除星座公共中位数；
4. `max(固定下限, k*MAD)` 自适应门限；
5. 支持逐频启停，Find X6 第三频判决关闭；
6. 保存逐频 `cs_found_freq` 和 `exclude_freq`。

R9仍有较高周跳标记率，但60秒分段阻止了错误状态长时间传播，是本轮K80/ACE5大幅改善的主要来源。后续仍应继续以GF/TDCP确认降低误报。

### 4.2 结果诊断

修复 `sparseVariables.m` 将 `exclude` 覆盖成 `cs_found` 的错误。最优结果验证：

- K80：逐频矩阵 `[3600,410,3]`，`cs_found` 与 `exclude` 可区分。
- ACE5：逐频矩阵 `[2272,410,3]`，`cs_found` 与 `exclude` 可区分。

### 4.3 随机模型

新增手机码/相位独立 C/N0 模型，支持不同高低 C/N0 标准差及星座因子。大幅放松到码 3--10 m 的R1--R4对X6/ACE5会造成滤波增益不足，因此最终R9恢复原随机模型，只保留算法基础设施供后续标定。

### 4.4 多路径

原算法为伪距高阶差分超过固定门限后硬剔除并冷却600秒。新增软模式使用星座MAD门限和Huber式码方差膨胀，不删除相位。R11短筛：

- K80：R9 P95 13.06 m，R11 13.04 m，差异不足以支持全时段采用。
- ACE5：R9 P95 23.78 m，R11 24.44 m，略有退化。

因此最终结果关闭多路径软权重，但代码能力保留。

## 5. 参数筛选摘要

- R1：稳健Doppler + 保守随机模型；K80有收益，X6/ACE5易发散。
- R2：关闭Doppler；有效率表面提高，但K80/ACE5达到公里级误差，否决。
- R3：R1 + 冷启动；尾部仍不稳定。
- R4：较温和随机模型；仅K80短筛较好。
- R5/R6/R8：恢复原随机模型，仅扫描稳健门限/MAD；K80稳定，X6精度不佳，ACE5仍受状态污染。
- R7：传统固定2 cycle；出现公里级尾部，否决。
- R9：60秒分段 + 稳健Doppler + 多历元冷启动；K80/ACE5最优。
- R10：300秒分段；状态污染持续时间过长，明显差于R9。
- R11：R9 + 软多路径；未超过R9。

- 当前形式协方差仍偏乐观，不能仅凭内部sigma评价精度。
